T07(alert): 历史列表与筛选

实现内容：新增 GET /api/alerts/history 端点，支持分页、severity/source/clearedBy/keyword/from/to 筛选，服务端按 clearedAt DESC, id 排序。新增 AlertHistoryView record 与 AlertHistoryRepository 实现查询与计数。

验收结果：
- 有数据时 → 返回 items[] 为 AlertHistoryView 数组，total 为总数
- 无数据时 → 返回 {\"items\":[],\"total\":0}，非 null
- size > 100 → 自动夹取为 100，不报错
- size < 1 → 返回 400
- 筛选 severity、source、clearedBy、keyword（模糊匹配 message）、from/to（对 clearedAt）均正常工作
- 排序：clearedAt DESC, id DESC
- 无 export 接口（审计模块负责）
- @RequirePermission(obj=\"alert\", act=\"read\”) 授权正常
