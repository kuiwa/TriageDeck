## 2026-11-27 修复：审计时间线 500（from/to 时间格式）

- 现象：`GET /api/audit/events?from=2026-11-21T05:54&to=2026-11-28T13:54...` 返回 500。
- 根因：前端 `datetime-local` 值无秒/无时区，后端 `Instant.parse(from)` 要求完整 ISO instant（带 Z），抛 `DateTimeParseException` → 500。
- 后端修复：`AuditController` 新增 `parseInstantTolerant`（Instant → OffsetDateTime → LocalDateTime(按 UTC) 依次尝试）；非法输入返回 400 `VALIDATION_FAILED` 而非 500；查询/导出统一传规范化 `fromInstant.toString()`；422 导出错误改用 `writeJsonError` 复用。
- 前端修复：`getAuditEvents`/`exportAuditEvents` 发送前用 `toIsoUtc`（datetime-local → ISO UTC）；`AuditTable.defaultFrom` 改为本地时区默认值（原用 UTC 切片当本地）。
- 测试：新增 `AuditControllerTimeParseTest`（Z / datetime-local / +08:00 / 非法）。
- 验证：`./gradlew :audit:test` 通过；前端 `npx tsc -b`、`npx vite build` 通过。
