T08(audit): 审计写入（@Auditable切面、403审计、Keycloak采集）

实现内容：新增@Auditable注解（platform模块）、AuditAction/Outcome/ActorType/TargetType枚举、AccessDeniedAuditPort接口和AuditTargetResolver SPI。audit模块新增AuditWriterImpl（REQUIRES_NEW事务）、AuditCommand记录、AccessDeniedAuditRecorder（403审计入口）、AuditDetailSanitizer（白名单脱敏）和IpMasker（IP网段脱敏）。

验收结果：
- @Auditable(action="ALERT_CLEARED", target="ALERT") 已标注在 AlertClearService.clear() 上
- 业务成功 → 1条 ALERT_CLEARED/SUCCESS 审计记录，detail 包含告警快照
- 业务抛异常 → 1条 FAILED 审计记录，detail.errorClass 有值
- 主业务回滚 → 审计记录仍然存在（REQUIRES_NEW 事务）
- 403 越权 → JsonAccessDeniedHandler 调用 AccessDeniedAuditPort → 1条 ACCESS_DENIED/DENIED 审计记录，detail 包含 path/method
- 401 不产生审计记录
- detail 中不含 token/password/完整 IP（IpMasker/AuditDetailSanitizer）
- IP 脱敏：10.20.3.77 → 10.20.3.0/24
